# Patterns for `restic backup --exclude-file` (see `make backup`).
# Matched against absolute paths. A pattern without a leading / matches the end
# of any path, so `.cache` is every .cache directory and `.local/share/Trash` is
# that folder under any home. Regenerable or duplicated data stays out, so a
# snapshot is a few tens of GB instead of ~300 GB. All of `.git`, `.config`,
# `.ssh`, `Documents` and the agent databases are kept.
